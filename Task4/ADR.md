
### <a name="_b7urdng99y53"></a>**Название задачи:**  Передача ставок в кол-центр
### <a name="_hjk0fkfyohdk"></a>**Автор:**  Баранов Илья
### <a name="_uanumrh8zrui"></a>**Дата:** 29.10.2025
### <a name="_3bfxc9a45514"></a>**Функциональные требования**
|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :-: | :- | :- | :- |
| UC1 | Пользователь, кол-центр | Условия депозита | 1. Пользователь интересуется условиями открытия депозита в кол-центре. 2. Менеджер обращается к ресурсу с актуальными ставками. 3. Консультирует клиента по актуальным ставкам. |
| UC2 | Внешний кол-центр, сервис актуальных ставок, АБС | Актуальные ставки | 1. Сервис актуальных ставок рассчитывает по информации из АБС. 2. Отправляет внутреннему шлюзу электронной почты. 3. Внутренний шлюз связывается с внешним и отправляет на электронную почту партнерского кол-цетра файл со ставками. |
| UC3 | Внутренний кол-центр, сервис актуальных ставок, АБС | Актуальные ставки | 1. Сервис собирает актуальные ставки у АБС 2. Внутренний кол-центр запрашивает актуальные ставки у сервиса.|
### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**
|**№**|**Требование**|
| +R2 | Использование XLS файлов |
| +R3 | Использование шлюзов электронной почты |
| +R4 | Поддержка микросервисов |
### <a name="_qmphm5d6rvi3"></a>**Решение**
В текущая архитектура без сильных изменений не вносится дополнительных изменений. Добавляется новый функционал реализуемый с помощью микросервисов. Во внутреннем кол-центре необходимо поддержать взаимодействие с сервисом актуальных ставок. В АБС нужно поддержать REST API расчета ставок. 
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- Поддержка внешнего кол-центра в виде REST API. Что облегчит изменения, например, расчет ставок для особенных клиентов. 

**Недостатки, ограничения, риски**
- Не учитывается расчет ставок для особенных клиентов.
