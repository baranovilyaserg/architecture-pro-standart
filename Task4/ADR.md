### <a name="_qmphm5d6rvi3"></a>**Решение**
Фиксируется протокол файла с актульными ставками, версия 1. Добавляется новый функционал реализуемый с помощью микросервисов. Во внутреннем кол-центре необходимо поддержать взаимодействие с сервисом актуальных ставок. В АБС нужно поддержать REST API расчета ставок. Сервис актуальных ставок при обновлении дергает энд поинт внутреннего кол-центра, так же отправляет данные в провайдер электронной почты для внешнего кол-центра. Обуславливается время доставки внешнему кол-центру, если не были получены актуальные ставки спустя 1 час, внешний кол-центр запрашивает ставки вручную.

Сервис актуальных ставок, хранит рассчитанные ставки во внутренней БД. Файл с актуальными ставки подписывается сертификатом.
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- Поддержка внешнего кол-центра в виде REST API. Что облегчит изменения, например, расчет ставок для особенных клиентов. 
- Сервис создания файла для генерация файла со ставками, избыточное решение на данном этапе. Сервис актуальных ставок может сам генерировать и отправлять файлы.
**Недостатки, ограничения, риски**
- Не учитывается расчет ставок для особенных клиентов.
